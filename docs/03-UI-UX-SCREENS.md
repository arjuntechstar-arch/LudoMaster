# UI/UX Screen Blueprint

Create an original visual identity. Do not imitate another game's screen
composition, iconography, logo, typography or board art.

1.  Splash / update required / maintenance.
2.  Onboarding and guest/login.
3.  Profile creation.
4.  Home dashboard.
5.  Mode selection.
6.  Online player-count/rules selection.
7.  Matchmaking waiting screen with cancel.
8.  Create private room.
9.  Join room by code.
10. Private lobby with seats, invite, ready and settings.
11. Offline computer setup.
12. Local multiplayer setup.
13. Team setup.
14. Tournament list/details/bracket.
15. Main game board.
16. Pause/connection overlay.
17. Results and rewards.
18. Profile/stats/history.
19. Friends/search/requests/recent/block list.
20. Leaderboards.

22. Season.
23. Inventory/customization.

25. Club/social area (feature flag).
26. Inbox/announcements.
27. Settings/privacy/account.
28. Support/report player.
29. Terms/privacy/consent.
30. Error/offline states.

## Board Interaction

The board must remain readable on compact phones. Keep dice/action zone
reachable by thumb. Legal tokens pulse/highlight. Invalid tokens do not
respond as valid actions. Animation never blocks canonical state
synchronization. If animation falls behind realtime events, safely
fast-forward.

## Design System

Define semantic spacing, typography, elevation, corner radius, button
hierarchy, icon system, motion durations, touch targets,
focus/semantics, dark/light-ready color tokens and color-blind
accessibility considerations.

## Original Assets Needed

Logo, app icon, board, tokens, dice, avatars, themes, emoji/stickers,
sound effects, music, victory/capture effects. Store asset
licensing/provenance metadata.
